设置主密码

主密码用于加解锁本机保存的全部数据。它只存在于你的设备上，不会被上传，也无法被找回。

忘记主密码将无法恢复任何数据，我们不提供「找回密码」功能。

主密码无法找回，请务必牢记。忘记密码时只能清空数据重新开始。

本地数据无法读取

本机保存的数据已损坏或格式不正确，出于安全考虑我们不会自动修改或丢弃它。 你可以清空数据后重新开始。

清空会删除本机全部数据，且无法恢复。

需要通过 Live Server 访问

浏览器的加密接口（Web Crypto）只在安全上下文中可用。直接双击打开 HTML 文件（file://） 时接口会被禁用，应用无法安全地保存数据。

请在 VS Code 中右键 index.html → Open with Live Server，然后访问 http://127.0.0.1:5500 。
